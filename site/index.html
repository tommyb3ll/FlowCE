FlowCE

Calculus on your TI-84 Plus CE.

Type math the way it looks. Get exact answers the way your textbook writes them, and now the steps too.

Install Screens

Free and open source. For the TI-84 Plus CE and TI-83 Premium CE.

Install

You need a TI-84 Plus CE, its USB cable, and Chrome or Edge on a computer. The page reads your OS and chooses the installer: v2.1 through 5.8.4, v3 on 5.8.5. Installing erases the calculator's apps and archived files.

This browser can't reach a calculator. Use Chrome or Edge on a computer, or TI Connect CE.
Windows USB connection needs a driver update: install TI Connect CE 6.1 or newer, then close it and reconnect here.
  1. 1

    Connect

    Plug in the calculator and turn it on. Close TI Connect CE if it's open.

  2. 2

    Install

    Sends FlowCE.

  3. 3

    Finish on the calculator

    When it shows INST, press enter once. It installs and restarts by itself ("RAM Cleared"). Then apps → FlowCE.

Install with TI Connect CE: OS 5.3–5.8.4
  1. Clear the archive: 2nd + (MEM) → 7 → ▶ ARCHIVE → 3 → 2.
  2. Download FlowCE.b84 and send it with TI Connect CE.
  3. prgm → enter → enter opens arTIfiCE. enter starts INST, enter again installs.
  4. At "Success! Will now reset", press enter. Then clear, apps → FlowCE.
“Unknown OS version”, or updating the calculator

If INST shows “Unknown OS version”, stop and report your model, OS and boot-code versions. An OS update may leave the boot code unchanged, so upgrading is not a confirmed fix. If FlowCE already works, keep your OS.

If you choose to update, TI currently offers OS 5.8.5. TI says you cannot downgrade afterward.

  1. Back up the calculator's files to your computer with TI Connect CE.
  2. Use TI's update page and choose your exact calculator model.
  3. Keep the calculator connected and powered. In TI Connect CE, choose Actions → Send OS/Bundles to Calculators…, select the downloaded OS file, then Send. Wait until the transfer and restart finish. TI's illustrated instructions.
  4. Close TI Connect CE. Return here and connect again: this page detects 5.8.5 and selects arTIfiCE v3.
Install on OS 5.8.5 with TI Connect CE

Back up your files first. FlowCE replaces the other apps. Keep your current OS; upgrading isn't needed to use FlowCE.

  1. Clear the archive before starting: 2nd + → 7 → ▶ ARCHIVE → 3 → 2.
  2. Follow the official arTIfiCE v3 instructions for OS 5.8.5: install Inequalz, reset RAM, send arTIfiCE.8xp to RAM, open Inequalz's Functions screen, then send INEQUVAR.8xv. After the restart, press on if the screen stays black.
  3. apps → AsmHook2. Dismiss “Installation successful!” to return to the home screen.
  4. Download the version selected above: FlowCE or FlowCE Steps (beta). Send the bundle with TI Connect CE. Keep INST in RAM and AppIns files in Archive. Keep AsmHook2 until you run INST; do not reset or erase again between these steps.
  5. prgm → select INST by name → enter → enter. Ignore the bundle's program A; it is for older OS versions. Press enter at the install prompt, then wait for the countdown to finish.
  6. At “Success! Will now reset”, press enter. After “RAM Cleared”, clear, then apps → FlowCE.

Verified in CEmu on OS 5.8.5.0074 with boot code 5.6.1.0006. Calculators with newer boot code still need verification. If INST says “Unknown OS version”, report your model, OS and boot-code versions.

Trouble?
  • Connect fails on Windows: update TI Connect CE to 6.1 or newer, then unplug and replug the calculator.
  • Connect fails on a Mac or Chromebook: close TI Connect CE, then unplug and replug.
  • Linux: add a udev rule such as SUBSYSTEM=="usb", ATTRS{idVendor}=="0451", ATTRS{idProduct}=="e008", TAG+="uaccess" in /etc/udev/rules.d/69-ti-calc.rules, then replug.
  • Still not enough memory after the erase: some apps survive it (often TI's language apps). Delete them: 2nd + → 2 → Apps, del on each.
  • "RAM Cleared" but this page still waits: FlowCE is installed. Press apps → FlowCE.
  • Frozen at "Success! Will now reset": press the reset button on the back (a pen tip). FlowCE stays installed.
  • The calculator acts strangely: clear the RAM: 2nd + → 7 → 1 → 2. FlowCE stays installed.
  • OS 5.8.5: the page selects v3. Follow its calculator prompts, or use TI Connect CE. OS 5.8.4.0058 uses v2.1.
  • INST says “Unknown OS version”: see OS help and update instructions. Updating is not a confirmed fix for newer boot code.

Something else, or a wrong answer? Report it on GitHub or on the Cemetech thread.
